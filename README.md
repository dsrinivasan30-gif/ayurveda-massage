# Authentic Ayurveda Massage at Your Home

A responsive, high-converting landing page for an at-home Ayurvedic massage and wellness service.

## Project Structure
- `index.html`: Complete, self-contained single-page website with embedded responsive CSS, FontAwesome icons, Google Fonts (`Playfair Display` & `Plus Jakarta Sans`), and vanilla JavaScript for mobile navigation.

## Quick Launch Options

### Option 1: Double-Click
Simply double-click `index.html` in Windows File Explorer to open it in your default browser (Chrome, Edge, Firefox).

### Option 2: Live Local Server with Python
```powershell
python -m http.server 8000
```
Then visit: [http://localhost:8000](http://localhost:8000)

### Option 3: Live Local Server with Node (npx)
```powershell
npx serve .
```

1. **Header & Navigation**: Sticky herbal bar with mortar & pestle logo, smooth-scrolling desktop links, and mobile slide-out drawer.
2. **Hero Banner**: Engaging headline, value proposition, action buttons, and therapy visual.
3. **Benefits Ribbon**: 6 health and wellness highlights (stress relief, pain relief, weight loss, hair growth, peace of mind, well-being).

5. **Why Choose Us Grid**: At-home comfort, authentic herbal oils, personalized therapy, certified therapist.

7. **How It Works (4 Steps)**: Easy booking, therapist visit, customized session, lasting results.
8. **Meet the Therapist**: Trust-building bio and authentic herbal imagery.
